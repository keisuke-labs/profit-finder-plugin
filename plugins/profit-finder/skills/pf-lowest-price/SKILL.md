# pf-lowest-price

## 目的

台帳のカード 1 枚について、メルカリと eBay のいまの最安を実ページで調べ直し、保存済みの価格との差を並べて示します。調べた値は会話の中で使うだけで、保存しません。

調べるのは Claude in Chrome で開いた実ページです。ウェブ検索や保存済みの情報で代用しません。

## 手順

1. 対象のカードの `card_id` を決めます。利用者が示していなければ、`pf_ledger_search` や `pf_overview` で探して、どのカードか利用者に確かめます。`pf_ledger_search` は既定で出品済みのカードと利益の低いカードを除くので、見つからなければ `exclude_listed: false` と `min_profit: {enabled: false}` で探し直します。
2. `pf_ledger_get_card`（`card_id`）でカードを取得します。特定情報（名前・型番・グレード・言語など）と、比較に使う保存済みの値を控えます。保存済みの値は次のとおりに決めます。
   - メルカリ: `best_mercari_id` の候補の `price_jpy` です。その候補が `sold_out_listings` にある（売り切れ済み）ときは、売り切れ済みを除いた候補のうち最も安い `price_jpy` を使います。候補が無ければ「保存済みの値なし」と示します。
   - eBay: eBay の出品のうち、出品中のもので最も安い `price_usd` です。無ければ「保存済みの値なし」と示します。保存済みの `price_usd` に送料が含まれるかは分からないため、そのまま表示価格として扱います。
3. 特定情報から、メルカリと eBay それぞれの検索語を作ります。特定情報が足りず検索語を作れないときは、推測で検索せず、利用者に確かめます。
4. Claude in Chrome で新しいタブを作ります。人がログイン済みの Chrome を使い、ログイン・購入・出品の操作はしません。Claude in Chrome が使えないときは、その旨を伝えて止まります（ウェブ検索で代用しません）。
5. メルカリの検索結果を読みます。販売中・価格の安い順に絞った 1 ページ目だけを読みます。検索結果から商品ページを開く場合は、1 回の調査で 20 件までです。上限で止め、残りがあることを伝えます。
6. eBay の検索結果を読みます。検索結果を「価格＋送料の安い順」に並べ替えてから読み、売却済み（落札済み）の出品は対象にしません。最安は送料込みで選びますが、保存済みの値との差は表示価格どうし（送料を除く）で出し、送料は別の列に示します。開く検索結果ページは 1 回の調査で 3 ページまでです。上限で止め、残りがあることを伝えます。
7. メルカリと eBay のどちらでも、bot 対策の画面やログイン要求に当たったら、当たったサイトの調査はその場で止めます。もう一方のサイトをまだ読んでいなければ、続けて読みます。最後に、読めた側の結果だけを示し、止めた側は未確認と明記します。
8. 検索結果から最安の候補を選びます。グレード・言語などが特定情報と明らかに違うものは、最安の候補から除きます。同じ商品かどうか迷うものは、除かずに、その旨を添えます。
9. それぞれの最安を、URL と価格つきで示し、手順 2 で決めた保存済みの値との差を並べます。メルカリの差は `price_jpy` との差です。eBay の差は表示価格どうし（送料を除く）で出します。
10. 開いたタブを閉じます。途中で止めたときも閉じます。

## 書き込み前の確認

このスキルは書き込みません。`pf_ledger_set_soldout` を含め、書き込みのツールを呼びません。調べた価格も保存しません。

検索や商品ページの中で売り切れを見つけたときは、利用者に伝えるだけにします。売り切れを付けたいときは `pf-stock-check` を案内します。

## 失敗時

- pf のツールが見つからない、または未認証のときは、推測で答えず、`/mcp` で pf を認証するよう案内して止まります。
- Claude in Chrome が使えないときは、その旨を伝えて止まります。
- メルカリまたは eBay で bot 対策の画面やログイン要求に当たったときは、当たったサイトの調査はその場で止めて伝えます。もう一方のサイトをまだ読んでいなければ続けて読み、最後に、読めた側の結果だけを示し、止めた側の最安は未確認だと明記します。
- 検索結果が読み取れなかったときは、読めなかったことをそのまま伝え、値を推測で補いません。
